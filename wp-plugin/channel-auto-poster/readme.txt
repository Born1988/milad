=== Channel Auto Poster ===
Requires at least: 5.5
Tested up to: 6.6
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

ارسال خودکار مقالات جدید به کانال تلگرام و بله.

== Installation ==
1. افزونه را بارگذاری و فعال کنید.
2. تنظیمات ← ارسال به کانال: توکن ربات و شناسه کانال را وارد کنید.
3. ربات را ادمین کانال کنید و «ارسال پیام آزمایشی» را بزنید.
