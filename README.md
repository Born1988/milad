# isacofarsaei.ir — افزونه وردپرس و ربات تلگرام

## ۱) افزونه ارسال خودکار به کانال (`wp-plugin/channel-auto-poster`)
1. پوشه را zip کنید و در وردپرس: افزونه‌ها ← افزودن ← بارگذاری.
2. تنظیمات ← **ارسال به کانال**:
   - تلگرام: توکن از @BotFather، شناسه کانال (`@name` یا `-100...`)؛ ربات باید ادمین کانال باشد.
   - بله: توکن از «بات‌فادر» بله (API: `tapi.bale.ai`)، شناسه کانال؛ ربات ادمین کانال باشد.
3. «ارسال پیام آزمایشی» را بزنید. از این به بعد هر مقاله‌ای که منتشر شود (عنوان + خلاصه + لینک + تصویر شاخص) خودکار ارسال می‌شود. در ویرایشگر مقاله می‌توان ارسال را غیرفعال یا دوباره انجام داد.

## ۲) ربات عیب‌یابی خودرو (`telegram-bot`)
1. پوشه را روی هاست (HTTPS، PHP با cURL) آپلود کنید.
2. `config.php` را پر کنید (توکن، `secret` تصادفی، شناسه عددی ادمین، تلفن).
3. یک بار باز کنید: `https://دامنه/telegram-bot/setup.php?key=SECRET` تا webhook ثبت شود.
4. برندها/مدل‌ها/مشکلات و راه‌حل‌ها را در `data/catalog.json` ویرایش و اضافه کنید (بدون نیاز به تغییر کد).

مسیر منو (دکمه‌های شیشه‌ای): برند ← مدل ← بخش خودرو ← مشکل ← راه‌حل ← «حل شد / ارتباط با کارشناس».
